# Easy Speak: Learn English

Мобильное приложение для изучения английского языка с игровым подходом. Проект сочетает классические методы обучения (карточки, заполнение пропусков) с современными технологиями хранения данных (локальная база Room + облачная синхронизация Firebase) и интуитивно понятным интерфейсом на Jetpack Compose.

<a name="о-проекте"></a>
🎯 **О проекте**

**Почему был создан этот продукт?**  
Bebeka появился как практическая реализация идеи доступного и увлекательного изучения английского языка. В отличие от многих существующих приложений, мы сделали упор на офлайн-режим с автоматической синхронизацией при наличии интернета, а также на систему мотивации через игровые механики (баллы, серии правильных ответов).

**Какую проблему он решает?**  
Приложение предоставляет структурированную систему для пополнения словарного запаса, тренировки грамматики и развития навыков перевода, не требуя постоянного подключения к сети. Пользователь может заниматься где угодно, а прогресс будет сохранён и синхронизирован при следующем подключении.

**В чём его ключевые преимущества?**

- **Офлайн-доступ** – все данные дублируются локально в Room, приложение полностью работоспособно без интернета.
- **Облачная синхронизация** – прогресс, аватарки и баллы сохраняются в Firebase Firestore и доступны на любом устройстве после входа.
- **Три режима игр** – угадай животное по картинке, подбери перевод слова, дополни предложение.
- **Система мотивации** – начисление баллов с увеличивающимся бонусом за серию правильных ответов.
- **Мультиязычность** – встроенная смена языка интерфейса (английский/русский) с сохранением выбора.
- **Профиль пользователя** – аватарка (загрузка из галереи), имя, статистика, возможность выйти или сменить язык.

<a name="технологии"></a>
## Технологии

Для работы приложения требуется Android 6.0 (API 23) или выше.

**Стек проекта:**

- **Язык и платформа:** Kotlin, Android SDK
- **UI:** Jetpack Compose, Material 3
- **Локальная база данных:** Room (SQLite)
- **Облачное хранилище:** Firebase Firestore
- **Аутентификация/сессии:** SharedPreferences + Firebase 
- **Навигация:** Jetpack Navigation Compose
- **Работа с изображениями:** Base64 (для Firestore), сжатие и конвертация Bitmap
- **Архитектура:** Clean Architecture (слои data, domain, presentation), Repository паттерн

<a name="возможности"></a>
## Возможности

- **👤 Регистрация и вход:** создание нового пользователя (имя, email, пароль) с сохранением в локальную БД и, при наличии сети, в Firestore.
- **📊 Главный экран:** отображение ника и баллов текущего пользователя, три кнопки для перехода к играм.
- **🦁 Игра «Угадай животное»:** показывается изображение животного, пользователь вводит название на английском. За правильный ответ начисляются баллы.
- **🔤 Игра «Угадай слово»:** даётся слово на одном языке, нужно выбрать правильный перевод из четырёх вариантов.
- **✍️ Игра «Дополни предложение»:** нужно вставить пропущенное слово в английское предложение.
- **🏆 Система баллов:** за каждый правильный ответ начисляется 1 балл + бонус 0.2 за каждую последующую правильную попытку подряд (до 5). Серия сбрасывается при ошибке.
- **🌐 Смена языка интерфейса:** поддерживаются английский и русский языки. Выбор сохраняется и применяется сразу.
- **🖼️ Профиль:** отображение аватарки, имени, возможность сменить аватарку из галереи (сжимается до ~100 КБ), выйти из аккаунта или сменить язык.
- **🔄 Синхронизация:** при наличии интернета данные (баллы, аватарка) автоматически синхронизируются с Firestore.

<a name="использование"></a>
## Использование

1. **Начало работы:**
   - При первом запуске показывается онбординг (3 экрана).
   - Затем выбор языка интерфейса.
   - Регистрация или вход (если уже есть аккаунт).

2. **Главный экран:**
   - Вверху отображается ваш ник и текущие баллы.
   - Три кнопки запускают соответствующие игры.

3. **Процесс игры:**
   - **Животное:** смотрите на картинку, вводите ответ → кнопка Check → переход на экран результата (зелёный/красный фон). Можно попробовать снова или перейти к следующему животному.
   - **Слова:** выбираете вариант ответа → Check → правильный вариант подсвечивается зелёным, неправильный – оранжевым. Next – новое слово.
   - **Предложения:** вводите пропущенное слово → Check → поле окрашивается в зелёный/красный, кнопка меняется на Next → следующее предложение.

4. **Профиль:**
   - На главном экране нажмите на свой аватар/ник для перехода в профиль.
   - Здесь можно изменить язык, загрузить новую аватарку или выйти.

<a name="разработка-и-тестирование"></a>
## Разработка и тестирование

Проект построен с использованием современных подходов к Android-разработке:

- **Модели данных:** `User`, `Animal`, `SentenceData`, `Words` и др.
- **Репозитории:** `UserRepository` инкапсулирует работу с Room и Firebase.
- **ViewModel:** (частично, в играх логика внутри экранов с `remember` + корутины)
- **Работа с БД:** Room DAO (`UserDao`) для локальных операций, `FirestoreService` для облачных.
- **Управление сессией:** `SessionManager` на базе SharedPreferences.

### Разработка и тестирование

Проект построен на современном стеке Android-разработки с использованием **Jetpack Compose** для декларативного построения UI и архитектурного паттерна, близкого к **MVVM** и **Clean Architecture**. Код организован следующим образом:

- **Модели данных:** `User`, `Animal`, `SentenceData`, `Words` и другие сущности, отражающие предметную область.
- **Локальное хранилище:** Room (SQLite) с DAO-слоем (`UserDao`) для работы с пользователями.
- **Облачное хранилище:** Firebase Firestore через сервис `FirestoreService`, обеспечивающий синхронизацию данных (баллы, аватарки).
- **Репозитории:** `UserRepository` инкапсулирует логику работы с данными, объединяя локальные и удалённые источники.
- **UI-компоненты:** Composables, разделённые по экранам (`screen/`), с использованием `remember` и корутин для управления состоянием.
- **Навигация:** Jetpack Navigation Compose с типизированными маршрутами.
- **Управление сессией:** `SessionManager` на базе SharedPreferences.

<a name="тестирование"></a>
#### Тестирование

Проведено комплексное тестирование, охватывающее ключевые функциональные модули и пользовательские сценарии.

<a name="модульное-тестирование"></a>
**Модульное тестирование** проверяет корректную работу отдельных компонентов:
- **Регистрация:** валидация полей, проверка уникальности email, создание пользователя в локальной БД и Firebase, обработка ошибок.
- **Главный экран:** загрузка данных текущего пользователя, отображение ника и баллов, навигация по кнопкам.
- **Игра «Угадай животное»:** генерация случайного животного, проверка ответа с учётом регистра, переход на экран результата, начисление баллов.
- **Игра «Угадай слово»:** формирование вариантов ответа, подсветка правильного/неправильного выбора, обновление счёта, переход к следующему слову.
- **Игра «Дополни предложение»:** проверка пропущенного слова, изменение цвета поля, активация кнопки «Далее», начисление баллов.
- **Профиль:** загрузка и отображение данных, смена аватарки (сжатие, сохранение в БД и Firebase), смена языка, выход из аккаунта.

<a name="интеграционное-тестирование"></a>
**Интеграционное тестирование** проверяет взаимодействие модулей в рамках сквозных пользовательских сценариев (пути T1–T8):

- **T1 (1-2-3-4-5):** запуск приложения → онбординг → выбор языка → авторизация → главный экран.
- **T2 (1-5-6-7-5):** главный экран → игра «Угадай животное» → правильный ответ → экран результата → возврат.
- **T3 (1-5-8-5):** главный экран → игра «Дополни предложение» → ввод ответа → проверка → следующий → возврат.
- **T4 (1-5-9-5):** главный экран → игра «Угадай слово» → выбор варианта → проверка → следующий → возврат.
- **T5 (1-5-10-3-5):** главный экран → профиль → смена языка → возврат.
- **T6 (1-5-10-4-5):** главный экран → профиль → выход → повторный вход.
- **T7 (1-5-10-5):** главный экран → профиль → возврат.
- **T8 (1-5-6-5):** главный экран → игра «Угадай животное» → возврат без ответа.
